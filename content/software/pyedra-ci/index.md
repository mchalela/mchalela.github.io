**Role:** contributor. **Code:** [milicolazo/Pyedra](https://github.com/milicolazo/Pyedra)

Pyedra fits phase curves to asteroid photometry. I set up its continuous integration: a pytest suite with fixtures for the reference data, a GitHub Actions matrix across Python versions, linting, and the documentation build, so the maintainers could merge contributions with confidence.
