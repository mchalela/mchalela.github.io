what fits a freelance scientific Python developer best.

## Shortlist

1. Astro Nano, as the skeleton for a custom astronomy / solarpunk skin.
2. Milky Way, if the celestial motif should come from the template itself.
3. Hugo Profile, if staying off the Node toolchain.
4. DevPortfolio, if no build step at all.
5. al-folio, if the academic CV and the freelance pitch live on one site.

No existing template matches an astronomy + software + solarpunk feel. Plan: pick a minimal
skeleton and replace palette (cream, forest green, moss, sun gold, one deep indigo), fonts
(Fraunces or Cormorant for headings, clean sans or mono for body) and SVG assets
(constellation line-art blended with botanical shapes).
